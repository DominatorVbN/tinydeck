Compatible pads

TinyDeck supports the CH57x family behind most “mini keyboard” and “macro keypad” pads, usually $10–30 with Windows-only software.

USB IDTypical layoutStatusNotes
1189:88903 keys + knob, 6 keys + knob, 4 keysSupportedLighting is an effect number only.
1189:8840 · 8842 · 88503×4 / 3×3 / 3×2 + knobsSupportedLayers, delays, coloured per-layer lighting.
1189:8851 · 514c:88513–15 keys + knobsSupported
514c:88504×4 keysExperimentalNot yet confirmed on hardware. Please report!
1189:8890 “LCKEY”3 keys + knob + screenNot supportedUses a different format. TinyDeck won't write to it.

How to check your pad

Plug it in and open TinyDeck

The sidebar shows the pad, and Pad Info shows its USB ID.

Or use System Information

Apple menu ▸ About This Mac ▸ More Info ▸ System Report ▸ USB. Look for vendor ID 0x1189 or 0x514c.

“Supported” means TinyDeck's output matches independent implementations byte for byte, and the model has been used with real hardware. Help confirm more pads with Help ▸ Report My Pad.
